# Illustrations des cartes

Un fichier par lieu, nommé `<id>.svg`, avec le même id que dans `src/cartes/lieux.ts` (par exemple `tour-eiffel.svg`).

- Format carré, fond transparent : la carte pose déjà le fond crème.
- Laisser de l'air en haut : le titre du lieu s'affiche par-dessus.
- Si le fichier manque, la carte affiche une illustration de remplacement.
